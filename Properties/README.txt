Parking Lot Tool - a mod for Cities: Skylines II
================================================

Draw an area, and the tool builds a real parking lot into it: bays, aisles,
entrances, markings, surfaces - and cars that actually park there.


INSTALL

Copy this whole folder ("ParkingLotTool") into:

  %USERPROFILE%\AppData\LocalLow\Colossal Order\Cities Skylines II\Mods\

Then start the game. Keep every file in the folder, including the .pdb files -
without them a crash report has no line numbers, and it is worth half as much.


YOU ALSO NEED

Two mods from Paradox Mods. Without them the panel opens but every icon shows
as a white box:

  Unified Icon Library   https://mods.paradoxplaza.com/mods/74417/Windows
  Asset Icon Library     https://mods.paradoxplaza.com/mods/79634/Windows

Harmony does NOT need installing. It ships with the mod as 0Harmony.dll.


REPORTING A PROBLEM

This is work in progress. It builds working parking lots, but things still
break, and a report is the only way they get fixed.

Report it here:

  https://github.com/KruemelGames/ParkingLotTool/issues

First use the "Report a problem" tab in the panel. It writes a single .zip into
your Cities: Skylines II logs folder with everything needed to look into it,
including a crash report if the game died last time. Drag that file into the
issue.

Then say, briefly: what you did step by step, what you expected, what happened
instead, whether the game crashed, and which other mods were running. Please do
not paste logs - everything technical is already in the file.

One thing to know before you upload: a crash report includes the game's own
Player.log, and that contains your Windows user name, your Steam ID, your save
game names and your mod list. Issues are public. If that bothers you, open the
.zip and remove Player.log and Player-prev.log first.
